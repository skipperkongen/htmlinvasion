Unleash it on any page: the bookmarklet

This section is a bunker: it has the class invasion-ignore, so the helicopter leaves it alone. Add that class to any element you want to protect.

You opened this page as a local file. The demo above works, but a bookmarklet that points at file:// won't load on other websites. Serve this folder over http (for example python3 -m http.server, then open http://localhost:8000/), or enter the public URL where you uploaded these files below.

🚁 Attack Helicopter

Add the bookmarklet

  1. Show your bookmarks bar: Ctrl+Shift+B (Windows/Linux) or Cmd+Shift+B (Mac).
  2. Drag the green Attack Helicopter button above onto the bookmarks bar.
  3. Can't drag (e.g. on mobile)? Bookmark any page, edit the bookmark, and paste the code from the box below as its URL.

Use it

  1. Open any website and click the Attack Helicopter bookmark.
  2. A Launch Attack Helicopter button appears in the bottom right corner.
  3. Click it, turn up the volume, and watch the page get destroyed one element at a time. Click Abort mission to call it off. Reload the page to undo the damage.

Good to know

  • The bookmarklet loads attackhelicopter.js and the mp3 files from the URL above, plus jQuery from code.jquery.com, without touching the page's own jQuery.
  • Some sites (GitHub, banks, many big web apps) have a Content Security Policy that blocks outside scripts. The bookmarklet tells you when that happens; there's nothing to do but pick another site.
  • Nothing is changed for real: everything happens in your browser tab only.
